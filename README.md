# sin.identidad
##Título: Sin identidad
Pieza interactiva con Aprendizaje de Máquina 

Esta pieza busca crear un diálogo entre lo que queremos ser y lo que somos, como una cuestión de identidad a través de preguntas existenciales que el público puede ver. En este caso, se representa a través de unas máscara de teatro para hacer alusión a este conflicto interno.

Con ayuda de aprendizaje de maquina o Machine Learning, fue posible realizar este proyecto por medio del BodyPose, utilizando en específico el punto no.2 del rostro, el cual corresponde al ojo. Así, el público puede interactuar posicionándose frente a la cámara para experimentar esta cuestión de identidad.

El proceso técnico fue algo conflicrtivo, ya que, a pesar de contas con las bases de programación necesarias para realizar el proyecto, adaptarlo a situaciones específicas resultó un poco problemático. Por cuestiones de tiempo, el resultado final consta solo de dos mitades de máscara; sin embargo, se tiene la consciencia de que, con un poco más de tiempo, el proyecto podría haberse desarrollo a mayor escala. 

El uso del aprendizaje de máquina en el arte digital ha abierto nuevas posibilidades. Personalmente, es un área a la que nunca me imaginé que se pudieran hacer proyectos tan impactantes, donde no solo se mezcle código, sino también otras disciplinas como la danza. Creo que es una herramientas que tal vez aún no sea tan popular, pero realmente se le puede sacar provecho y se puede utilizar para muchos propósitos y temas. 

No solo permite al artista generar imágenes y sonidos interactivos y obras visuales que tal vez antes requerían de grandes equipos técnicos, sino que también facilita la colaboración entre artistas y permite una interacción personalizada al público. 

En esta asignatura en particular, el Machine Learning se convirtió en una herramienta fácil de comprender y divertida; al ser interactiva, permite que varias personas puedan dar su opinión y participar en este proyecto. En generaL, brinda al artista una libertad inmensa para explorar y experimentar..
